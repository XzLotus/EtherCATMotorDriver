# 来源与改编记录

## 可读取资料

用户指定的项目目录中，大多数应用 `.c/.h` 以二进制封装形式保存。同目录存在同名项目的可读注释副本，公开版以该副本作为代码阅读和通用逻辑提取来源。

目标目录中的三份可读头文件，与注释副本对应文件在去除注释和空白后内容一致；这些文件用于核对接口，原始控制结构与参数定义已整体移除。封装源码与可读副本的版本关系，依据工程结构和这些接口对照记录。

## 公开文件的形成

| 公开文件 | 来源和处理 |
| --- | --- |
| `src/comms/crc16.c` | 从注释副本串口模块提取标准 CRC16 函数，重命名并增加空指针处理 |
| `src/comms/modbus_demo.c` | 参考原串口请求处理流程拆分，使用独立上下文和示例寄存器，补充长度、范围、广播及响应容量检查 |
| `src/telemetry/demo_telemetry.c` | 参考原波形封装方式改编，移除内部变量绑定，改由调用方提供数据，使用显式字节序与容量检查 |
| `reference/haawking_sci_rx.c` | 根据原 SCI 接收中断摘录改写，展示接收回调及标志清除关系 |
| `src/drive/redacted_drive.c` | 新增公开占位实现，所有调用保持输出关闭 |
| 演示、测试、构建与检查脚本 | 为本次公开版本新增 |

公开寄存器从零初始化，演示中寄存器 0 的数值 42 为合成数据。遥测样例中的浮点值也采用合成数据，原产品地址、单位换算、控制系数与运行数据已移除。

## 文件保全

提取在独立目录进行。原工程与可读注释副本均保留原样，提取前后逐文件 SHA-256 对照记录保存在本地审查目录。公开仓库从经过审查的文本文件集合建立快照。

厂商 SDK、数学库、Flash API、链接脚本、二进制封装文件及编译产物均已从发布包剔除。
