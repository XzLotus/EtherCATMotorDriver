# 验证记录

验证日期：2026-11-16。

## 已执行

- 主机编译使用 GCC，C99，`-Wall -Wextra -Wpedantic -Werror`，三个可移植目标全部通过。
- 24 组 Modbus 场景通过，覆盖 CRC 已知向量、03/06/10、边界数量、越界、广播、从站过滤、错误 CRC、分片、连续帧、发送忙状态和接收溢出后的新请求。
- 其中执行 1024 组确定性异常输入，覆盖至 256 字节的输入长度。
- 去敏感电机后端在初始化、命令提交、极值和无效参数情况下均保持 `output_enabled = 0`。
- 主机演示读取合成寄存器，响应为 `01 03 02 00 2A 39 9B`。
- 使用原工程已有 SDK 头文件，对 CAN、EEPROM、RS485、QSPI 四个 N32 源文件执行 GCC `-fsyntax-only` 检查，全部通过；该步骤仅做语法和声明检查。
- 原工程 227 个文件的 SHA-256 在提取前后完全一致。

## 验证范围

主机编译与行为测试覆盖 `src/`、`ports/host/`、`examples/`、`tests/`。`ports/n32/` 为硬件阅读与移植样例，SDK 由使用者另行提供。

公开版的主机测试验证内存传输环境下的报文处理。UART 间隔、总线终端与偏置、DMA 长时间运行、目标 MCU 的中断时延、EEPROM 掉电恢复及 EtherCAT 主站互操作仍需在硬件环境完成专项验证。

CI 工作流会在仓库推送后执行发布清单检查与同一组主机测试，实际运行结果以 GitHub Actions 页面为准。
