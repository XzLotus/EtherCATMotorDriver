# 验证记录

日期：2026-11-17。

## 已完成

- 三个主机目标采用 C99 与 GCC 编译，开启 `-Wall -Wextra -Wpedantic -Werror`，全部通过。
- 23 组 Modbus 场景通过，覆盖 CRC 已知向量、从站地址、03/06/10、最大数量、越界、无效数量、广播、CRC 损坏、响应缓冲区容量及短帧。
- 其中包含 512 组确定性异常输入，输入长度覆盖至 256 字节。
- 遥测序列化通过已知浮点字节序、帧尾、空指针和容量检查。
- 驱动占位接口在交替运行请求和重新初始化后，输出始终保持关闭。
- 主机示例生成 `01 03 02 00 2A 39 9B` 的寄存器读取响应及 20 字节合成遥测帧。
- 原工程 192 个文件、可读注释副本 136 个文件的 SHA-256 在提取前后保持一致。
- 22 个候选发布文件通过敏感字段、产品寄存器地址、本地路径及二进制封装扫描。
- 发布检查已验证：文档编辑可正常通过，源码摘要变化、二进制内容、模拟凭据和清单外文件会触发检查失败。

## 验证范围

主机验证覆盖 `src/`、`examples/`、`tests/` 中的公开模块。`reference/` 为设备 SDK 环境下的集成阅读摘录，具体中断配置、字节缓存同步、总线静默间隔与收发电气时序需要目标板验证。

原项目私有驱动实现已移除；主机演示执行内存通信、合成数据封装和占位接口调用。设备端编译、功率输出、性能指标与整机测试由实际硬件工程单独验证。
