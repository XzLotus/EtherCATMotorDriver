## 发布检查

`tools/check_public_release.py` 对全部公开文件执行明确清单检查、UTF-8 检查、二进制内容检查和常见凭据格式检查，并对源码、脚本、CI 配置核对 SHA-256。Markdown 文档保留同一套内容检查，支持直接在线编辑。

新增文件时，先审阅内容，再更新脚本中的明确文件清单。修改源码后执行：

```sh
python tools/check_public_release.py --refresh-manifest
python tools/check_public_release.py
python tools/build_and_test.py
```

将已审阅的变更和 `public-files.json` 一起提交。GitHub Actions 会再次执行清单检查和主机测试。
