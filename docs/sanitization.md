# 去敏感内容发布说明

## 公开内容

采用通信与外设样例，并在新目录中建立公开版。`public-files.json` 。

| 内容 | 处理方式 |
| --- | --- |
| Modbus RTU | 保留协议逻辑，拆分硬件聚合头依赖 |
| RS485、CAN、EEPROM、QSPI | 保留通信与外设访问，统一 SDK 入口，移除产品名称 |
| 机密电机驱动算法与预编译库 | 从发布内容中整体移除 |
| 机密运动规划、细分与电流控制、回零细节 | 从发布内容中整体移除 |
| 机密电机参数、标定数据、传感器换算和对象字典 | 从发布内容中整体移除 |
| 机密私有串口协议、历史脚本、调试记录 | 从发布内容中整体移除 |
| 可执行固件、链接映射、调试文件、备份和本地配置 | 从发布内容中整体移除 |
| 厂商 SDK 与 EtherCAT 协议栈 | 公开包仅引用依赖名称和集成结构 |
| 公开演示寄存器和电机接口 | 使用独立的合成数据和脱敏后端 |

发布包中的接口、源码、文档和文件清单一起接受检查；算法二进制同样列入剔除范围。

## 与原工程的关系

共提取 10 个通信与外设源码文件。公开版进行 UTF-8 与换行统一，替换聚合头依赖，移除产品标识与作者占位字段。CAN 文件的说明改为“报文读写、过滤器配置及接收中断回调”，与现有实现保持一致。

主机适配器、通用电机接口、示例、测试、发布检查与文档为公开版新增内容。原工程的开发目录和文件保持原样；发布从这份已脱敏快照开始建立提交记录。

## 后续更新

1. 只加入已审查的文本源码与文档，并同步更新检查脚本中的明确文件清单。
2. 执行 `python tools/check_public_release.py --refresh-manifest` 更新文件摘要。
3. 执行 `python tools/check_public_release.py` 和 `python tools/build_and_test.py`。
4. 检查暂存文件与差异，再提交到公开仓库。

CI 对公开文件清单与主机行为测试执行相同检查。公开包用途为招聘展示与技术评审。
